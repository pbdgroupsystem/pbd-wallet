# ภาพพื้นหลังธีมเทศกาล (PBD Wallet)

วางไฟล์ภาพในโฟลเดอร์นี้ ตั้งชื่อตามธีม แล้ว Wallet จะใช้เป็นพื้นหลังเต็มจอช่วงเทศกาลเอง (โหมดฟิลเตอร์กระจก)

| ไฟล์ | เทศกาล |
|---|---|
| loy.jpg | ลอยกระทง |
| xmas.jpg | คริสต์มาส |
| newyear.jpg | ปีใหม่ |
| cny.jpg | ตรุษจีน |
| buddha.jpg | วันพระใหญ่ (มาฆะ วิสาขะ อาสาฬหะ เข้า/ออกพรรษา) |
| songkran.jpg | สงกรานต์ |
| mother.jpg | วันแม่ |
| father.jpg | วันพ่อ |

ขนาดแนะนำ: แนวตั้ง 1080 × 2340 px · JPG ไม่เกิน ~500 KB · ไม่มีปุ่ม/การ์ด/ตัวหนังสือของแอปในภาพ
จุดเด่นของภาพไว้ด้านบน (สูงราว 15% ของภาพ) และด้านล่าง (ราว 20%) — ช่วงกลางจะถูกการ์ดบังเป็นส่วนใหญ่
ไม่มีไฟล์ = ใช้พื้นหลังสีไล่ระดับเดิม · ใช้ภาพชื่ออื่นได้โดยใส่ "bg": "themes/ชื่อไฟล์.jpg" ในเทศกาลนั้นใน festivals.json
