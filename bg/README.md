# ภาพพื้นหลังสภาพอากาศ (PBD Wallet · ช่วงที่ไม่มีเทศกาล)

วางไฟล์ภาพในโฟลเดอร์นี้ ตั้งชื่อตามสภาพอากาศ (รองรับ .jpg / .png / .webp — แนะนำ .jpg แนวตั้ง 1080×2340 ขนาดไม่เกิน ~400 KB)

| ไฟล์ | สภาพอากาศ |
|---|---|
| `day.jpg` | ☀️ แดด (กลางวัน) |
| `night.jpg` | 🌙 กลางคืน (ฟ้าโปร่ง) |
| `cloudy.jpg` | ☁️ เมฆมาก |
| `rain.jpg` | 🌧️ ฝนตก |
| `storm.jpg` | ⛈️ พายุฝนฟ้าคะนอง |
| `fog.jpg` | 🌫️ หมอก |

- ไม่มีไฟล์ไหน = ใช้พื้นหลังสีไล่ระดับ + เมฆ/ฝนที่วาดด้วยโค้ดแทน
- มีภาพแล้ว: ซ่อนดวงอาทิตย์/เมฆ/หมอกที่วาดด้วยโค้ด เหลือเม็ดฝน ฟ้าแลบ และดาวกะพริบซ้อนบนภาพ
- ส่วนสำคัญของภาพควรอยู่ครึ่งบน (ด้านล่างถูกการ์ดบัง)
- ทดลองดู: เปิด Wallet ต่อท้ายลิงก์ `?fest=off&wx=rain` (day / night / cloudy / rain / storm / fog)
